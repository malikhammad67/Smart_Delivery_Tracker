# 🚚 Smart Delivery Tracking & Delay Analytics System

A Python-based logistics operations application that stores delivery records in SQLite, automatically detects late and overdue shipments, calculates delivery delays, analyzes driver and delivery-area performance, and exports management reports through a Streamlit dashboard.

## 🎯 Problem Statement

Logistics companies need to track delivery performance, identify delays, and monitor driver/area efficiency. Manual tracking leads to:
- Missed delivery deadlines
- Inefficient driver allocation
- Poor visibility into area performance
- Difficulty generating performance reports

## 💡 Solution

This application provides:
- **Delivery Management**: Add, track, and complete deliveries
- **Automatic Status Detection**: ON TIME, LATE, PENDING, OVERDUE
- **Analytics Dashboard**: Real-time metrics and visualizations
- **Performance Tracking**: Driver and area performance analysis
- **Export Capabilities**: CSV reports for management

## ✨ Features

- ✅ Add new deliveries with unique order IDs
- ✅ Automatic status calculation (ON TIME, LATE, PENDING, OVERDUE)
- ✅ Complete pending/overdue deliveries
- ✅ Search deliveries by Order ID or Customer Name
- ✅ Filter by Status, Driver, and Area
- ✅ Real-time dashboard metrics
- ✅ Driver performance tracking
- ✅ Area performance analysis
- ✅ CSV export functionality
- ✅ Sample data for testing
- ✅ Responsive UI with modern design

## 🛠️ Tech Stack

- **Frontend**: Streamlit
- **Backend**: Python
- **Database**: SQLite
- **Data Processing**: Pandas
- **Visualization**: Plotly, Streamlit Charts
- **Version Control**: Git, GitHub
